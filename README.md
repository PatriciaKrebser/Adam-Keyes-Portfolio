# Adam Keyes - Portfolio

Responsive portfolio website for Adam Keyes, a front-end developer.

## Live Demo

[View the website](https://patriciakrebser.github.io/Adam-Keyes-Portfolio/)

## Technologies

- HTML5
- CSS3
- Sass (SCSS)
- JavaScript
- Vite

## Features

- Responsive layout for desktop, tablet and mobile devices.
- Mobile-first development approach.
- Sass architecture with organized partials.
- Responsive typography and layouts.
- Interactive elements with hover states.
- GitHub Pages deployment.

## Installation

Clone the repository:

```bash
git clone https://github.com/PatriciaKrebser/Adam-Keyes-Portfolio.git
```

Install dependencies:

```bash
npm install
```

## Development

Start the development server:

```bash
npm run dev
```

Compile Sass:

```bash
npm run sass:watch
```
